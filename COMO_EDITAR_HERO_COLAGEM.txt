================================================================================

================================================================================
2. TROCAR UMA IMAGEM
================================================================================

2.1. Abra: resources/views/home.blade.php

2.2. Localize o bloco da peça que deseja trocar. Cada foto tem uma classe
     identificadora, por exemplo collage-piece--p1, collage-piece--p6, etc.

     Exemplo (foto p1 – canto superior esquerdo):

     <figure class="collage-piece collage-piece--polaroid collage-piece--p1 collage-piece--tilt-1">
         <img src="{{ asset('imagens_hero/Colagem/2.jpg') }}" alt="Preparativos do noivo" loading="eager">
     </figure>

2.3. Altere apenas o caminho dentro de asset():

     {{ asset('imagens_hero/Colagem/SUA_IMAGEM.jpg') }}

2.4. Atualize o texto alt="" para acessibilidade.

2.5. Salve o arquivo e recarregue a página no navegador (Ctrl+F5).

================================================================================
4. ALTERAR POSIÇÃO DE UMA PEÇA
================================================================================

4.1. Abra: public/css/custom-prod.css

4.2. Procure a classe da peça, por exemplo:

     .collage-piece--p1 {
         left: 8%;
         top: 10%;
         width: 11%;
         z-index: 3;
     }

4.3. Propriedades de posição:

     left   → distância da borda ESQUERDA (% da largura do mural)
     top    → distância do TOPO (% da altura do mural)
     bottom → use no lugar de top para ancorar pela base (ex.: floral-left)
     width  → largura da peça (% da largura do mural)

     DICA: use incrementos pequenos (1% ou 2%) e teste no navegador.

4.4. Exemplo – mover p6 mais para a direita e um pouco para baixo:

     .collage-piece--p6 {
         left: 42%;    /* era 38% */
         top: 44%;     /* era 40% */
         width: 17%;
         z-index: 5;
     }


================================================================================
5. ALTERAR TAMANHO DE UMA PEÇA
================================================================================

5.1. Ajuste a propriedade width na classe da peça:

     .collage-piece--p4 {
         width: 18%;   /* aumentar de 15% para 18% */
     }

5.2. A altura acompanha a proporção original da imagem automaticamente.

5.3. Para fotos oval (.collage-piece--oval), também é possível alterar:

     aspect-ratio: 3 / 4;   /* mais alta */
     aspect-ratio: 1 / 1;   /* circular */

5.4. Para recortar o conteúdo interno sem mover a moldura:

     .collage-piece--p9 img {
         object-position: 55% 20%;
     }

     object-position: horizontal vertical
     - 0% 0%   = canto superior esquerdo da foto
     - 50% 50% = centro
     - 100% 100% = canto inferior direito


================================================================================
6. ALTERAR BORDAS (MOLDURA POLAROID / OVAL)
================================================================================

6.1. Moldura estilo Polaroid (todas as fotos com collage-piece--polaroid):

     .collage-piece--polaroid {
         padding: 10px 10px 34px;
         background: #fff;
         box-shadow: 0 14px 32px rgba(0, 0, 0, 0.14);
     }

     padding: TOP  LADOS  BASE
              10px 10px  34px

     - Aumente os 10px laterais/superiores → borda branca mais grossa em cima e lados
     - Aumente o 34px inferior → efeito polaroid mais pronunciado

     Exemplo de borda mais grossa:
         padding: 14px 14px 48px;

6.2. Moldura oval (buquê):

     .collage-piece--oval {
         border: 5px solid #fff;
         border-radius: 50%;
     }

     - border: 8px solid #fff;  → moldura oval mais grossa


================================================================================
7. ALTERAR ROTAÇÃO (INCLINAÇÃO ARTESANAL)
================================================================================

7.1. Cada peça tem uma classe collage-piece--tilt-N com rotação fixa:

     .collage-piece--tilt-1 { transform: rotate(-3deg); }
     .collage-piece--tilt-2 { transform: rotate(2deg); }
     ...

7.2. Para inclinar mais a foto p3, edite:

     .collage-piece--tilt-3 { transform: rotate(-4deg); }

7.3. Valores positivos inclinam para a direita; negativos para a esquerda.


================================================================================
8. SOBREPOSIÇÃO (QUAL FOTO FICA NA FRENTE)
================================================================================

8.1. Use z-index na classe da peça:

     z-index: 2;   → mais atrás
     z-index: 8;   → mais na frente

8.2. Referência atual:
     - Fotos comuns: 2 a 5
     - Buquê oval e flores laterais: 7
     - Flor superior (peony): 8
     - Paleta de cores: 6

8.3. Se uma foto ficar escondida atrás de outra, aumente o z-index dela.


================================================================================
9. ALTERAR O FUNDO (LARGURA TOTAL DA TELA)
================================================================================

9.1. A imagem de fundo está em:
     public/imagens_hero/Colagem/fundo hero.png

9.2. Para trocar, substitua esse arquivo mantendo o mesmo nome OU altere no CSS:

     .hero-collage-mural {
         background-image: url('../imagens_hero/Colagem/fundo%20hero.png');
         background-size: cover;
         background-position: center center;
     }

     IMPORTANTE: se o nome tiver espaço, use %20 no CSS (fundo%20hero.png).

9.3. A largura total da tela é controlada por:

     .hero-collage-fullbleed {
         width: 100vw;
         margin-left: calc(50% - 50vw);
         margin-right: calc(50% - 50vw);
     }

9.4. Para mudar a altura do bloco de fundo:

     .hero-collage-mural {
         aspect-ratio: 4800 / 2995;   /* proporção original do PNG */
         min-height: clamp(300px, 48vw, 620px);
     }

     - Aumente min-height para o hero ficar mais alto
     - Altere aspect-ratio se trocar o fundo por outra proporção

================================================================================
11. AJUSTES NO CELULAR (TELAS PEQUENAS)
================================================================================

11.1. No final de public/css/custom-prod.css, dentro de:

      @media (max-width: 767px) { ... }

11.2. Há posições específicas para mobile (p1 a p9, buquê, flor, paleta).

11.3. Se no desktop ficou bom mas no celular sobrepõe demais, ajuste APENAS
      dentro desse bloco @media, sem alterar o desktop.

     Exemplo:
     @media (max-width: 767px) {
         .collage-piece--p6 { left: 10%; top: 45%; width: 32%; }
     }


================================================================================
12. FLUXO RECOMENDADO PARA TESTAR MUDANÇAS
================================================================================

1. Faça uma alteração pequena no CSS (ex.: left de uma peça).
2. Salve o arquivo.
3. Recarregue a home com Ctrl+F5 (limpa cache do navegador).
4. Teste em desktop e reduza a janela para ver o mobile.
5. Repita até a composição ficar equilibrada.

DICA: mantenha anotações das alterações (ex.: "p6 left 40% → 42%") para
      desfazer facilmente se necessário.


================================================================================
13. PROBLEMAS COMUNS
================================================================================

IMAGEM NÃO APARECE
    - Verifique se o arquivo existe em public/imagens_hero/Colagem/
    - Confira o nome exato (maiúsculas, extensão .jpg ou .png)
    - Caminho no HTML: asset('imagens_hero/Colagem/arquivo.jpg')

FUNDO NÃO OCUPA A TELA INTEIRA
    - Confirme que .hero-collage-fullbleed está no HTML envolvendo .hero-collage-mural
    - background-size deve ser cover

FOTO CORTADA DE FORMA ESTRANHA
    - Ajuste object-position na img da peça
    - Ou troque por imagem com proporção mais próxima da moldura

MUDANÇA NO CSS NÃO SURTE EFEITO
    - Limpe cache: Ctrl+F5
    - Confirme que editou public/css/custom-prod.css (não resources/css/app.css)
